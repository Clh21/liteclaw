# LiteClaw v0.8 模型兼容性与自检设计

## 目标

提高 OpenAI 兼容模型在结构化输出上的容错能力，并提供不会泄露密钥的本地诊断命令。重点覆盖 DashScope/Qwen 实测中记忆抽取返回对象包装或 Markdown JSON 时被放弃的问题。

## 结构化输出

- 新增一个无网络、无副作用的 JSON 提取模块。
- 接受纯 JSON、Markdown fenced JSON，以及 JSON 前后带简短说明的返回。
- 记忆抽取接受数组，或 `memories`、`items` 包装的数组。
- 摘要接受对象，或 `summary` 包装的对象；Planner 接受对象或 `plan` 包装的对象。
- 只解析第一个完整 JSON 值；缺字段和字段类型仍由现有 Pydantic/业务校验拒绝。

## 模型自检

- `python -m app.model_doctor` 从 `.env` 读取当前配置。
- 输出 provider、model、base URL、API Key 是否已配置，但绝不输出 Key 内容。
- 依次验证普通响应、calculator 工具调用和可解析 JSON。
- 进程退出码区分通过与失败；错误只给异常类型和脱敏原因。

## 边界

- 不自动修改用户配置。
- 不把提示词、模型响应或工具参数写入追踪。
- 不假定所有模型都支持强制 `response_format`，避免破坏兼容接口。
