# LiteClaw v1.0 本地身份与 RBAC 设计

## 目标

为自托管实例增加多用户 API Token 和角色权限，同时保持单用户部署默认行为不变。

## 身份模型

- `admin`：全部接口，包括用户和 Token 管理。
- `user`：除管理接口外的读写操作。
- `viewer`：只允许 GET/HEAD，只读访问。
- 用户 Token 使用安全随机数生成，只在创建响应中返回一次；数据库只保存 SHA-256 摘要。
- `LITECLAW_SERVER_API_KEY` 在 RBAC 模式下作为引导管理员密钥。

## HTTP 行为

- `LITECLAW_RBAC_ENABLED=false` 时保持现有单 Key 或无鉴权行为。
- 开启 RBAC 时必须配置 server API key。
- `/health` 保持公开；`/v1/admin/*` 仅 admin；viewer 写请求返回 403；无效 Token 返回 401。
- 本版提供角色级访问控制。会话、记忆、任务和评测的数据归属隔离在 v1.1 完成。
