# LiteClaw v0.7 OpenTelemetry 追踪设计

## 目标

v0.7 为 HTTP 请求、Agent run、模型步骤和工具调用增加同一上下文中的 OpenTelemetry spans，并通过可选 OTLP HTTP exporter 发送。默认不配置时保持零外部服务依赖。

## 配置与生命周期

`LITECLAW_OTLP_ENDPOINT` 为空时 tracing 状态为 disabled，代码使用轻量 no-op context manager。配置后按需导入 OpenTelemetry SDK，创建 Resource、TracerProvider、BatchSpanProcessor 和 OTLP HTTP exporter。缺少 optional dependency 或初始化失败时状态为 unavailable，主服务继续启动。应用关闭时 flush 并 shutdown。

## Span 层级

HTTP middleware 创建 `http.request` 根 span；同步 chat 在其下创建 `agent.run`，每次模型请求创建 `model.complete`，每个工具执行创建 `tool.execute`。SSE 后台任务没有原请求 context 时创建新的 `agent.run` 根 span。属性只记录 request/run/session id、路由、状态、step、tool name、耗时和成功状态，不记录 prompt、工具参数、API Key、cookie 或模型完整响应。

有有效 span 时响应加入 `X-Trace-ID`，便于从 API 结果定位 collector 中的 trace。现有 JSON 日志和 SQLite tool_events 保留。

## 完成标准

disabled、初始化失败、span 属性、trace id、runtime 模型和工具 span、HTTP span、health 状态均有测试；可选依赖和文档齐全；完整测试通过。
