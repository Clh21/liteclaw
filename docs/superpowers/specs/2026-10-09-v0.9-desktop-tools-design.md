# LiteClaw v0.9 桌面工具设计

## 目标

在显式开启后，让 Agent 能获取桌面尺寸与指针位置、保存屏幕截图，并执行鼠标点击、文本输入、快捷键和滚轮操作。

## 安全边界

- 默认 `LITECLAW_DESKTOP_ENABLED=false`，未开启时工具不会注册给模型。
- 截图和所有输入动作均标记为高风险，沿用持久化审批流程。
- 坐标、按键数量、文本长度、点击次数和滚动量均设上限。
- 截图只写入工作区 `data/desktop_screenshots/<session>`，文件名经过清洗。
- 工具结果不返回输入文本，不记录按键内容到 tracing。
- PyAutoGUI 是可选依赖，缺失或无图形会话时返回工具错误，不阻断主 API。

## 实现

新增可注入 backend 的 `DesktopManager`，生产环境延迟导入 PyAutoGUI，测试使用内存 backend，不产生真实鼠标键盘事件。独立工具类负责 Pydantic 参数验证和统一结果。
