# LiteClaw v0.4 部署与服务鉴权实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 并遵循 TDD。

**目标：** 增加可选 API Key 鉴权和可复现的单容器部署。

**架构：** FastAPI middleware 在 `/v1` 边界执行常量时间密钥校验；配置继续由 Settings 管理。Docker/Compose 固定单进程并持久化 `/data` 和 `/workspace`。

**技术栈：** FastAPI、Pydantic Settings、Docker、Compose、pytest。
