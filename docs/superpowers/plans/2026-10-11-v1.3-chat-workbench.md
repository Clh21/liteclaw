# LiteClaw v1.3 聊天记录工作台实现计划

> **面向 AI 代理的工作者：** 使用 executing-plans 逐任务实现。每项先写失败测试、确认失败、实现、验证、提交。

**目标：** 浏览消息，按日期分析，下载证据化 Markdown 报告。

**架构：** 在现有 API 上增加日期边界与 Markdown 响应；页面调用现有分页消息 API，报告渲染为纯函数。

**技术栈：** FastAPI、Pydantic、SQLite、原生浏览器 JavaScript、pytest、Ruff。

## 文件职责

- `app/api/chat_records.py`：日期输入、报告复用和 Markdown 响应。
- `app/chat_records/report.py`：报告 Markdown 纯函数。
- `app/chat_records/dashboard.py`：消息分页、日期控件、下载。
- `tests/test_chat_records_api.py`、`tests/test_chat_records_report.py`：边界、权限、报告内容和页面验收。
- `README.md`、`DEMO.md`、`pyproject.toml`、`app/main.py`：使用说明与版本。
