# LiteClaw v0.2 持久化任务服务实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 为 LiteClaw 增加可恢复的一次性和固定间隔后台任务、执行历史、有限重试及审批续跑。

**架构：** 使用 SQLite 保存任务定义和每次触发记录。独立 TaskRepository 负责原子领取，TaskService 复用 AgentRuntime 执行，TaskScheduler 只管理轮询、并发与生命周期，FastAPI router 暴露管理接口。

**技术栈：** Python 3.10、FastAPI、Pydantic 2、aiosqlite、asyncio、pytest/pytest-asyncio。

---
